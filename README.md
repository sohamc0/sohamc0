## About

I work on end-to-end monitoring for multi-domain optical networks, where each domain keeps its internal topology hidden. The published work uses deep reinforcement learning to choose monitoring lightpaths on a broker graph: one set for coverage, and a later set that tightens around a suspected failure.

M.S. Computer Science, San José State University. B.S. Computer Science, University of Maryland, College Park.
